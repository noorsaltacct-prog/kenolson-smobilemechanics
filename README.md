# Ken Olson’s Mobile Mechanics

Ready-to-upload static website. No installation or build step required.

## GitHub and Vercel
1. Extract this ZIP and upload its contents to your GitHub repository. index.html must be at the repository root.
2. Import the repository into Vercel.
3. Select Other as the framework. Leave the build command empty and use the repository root as the output directory.
4. Deploy.
